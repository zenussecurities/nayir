## 🎯 THE 5-STEP DEPLOYMENT PROCESS

### Step 1️⃣: Generate Secret Key (2 min)
```powershell
python -c "import secrets; print(secrets.token_urlsafe(50))"
```
**→ Copy the output**

### Step 2️⃣: Set Environment Variables in Vercel (3 min)
Go to: **Vercel Dashboard → Settings → Environment Variables**

Add these 5 variables:
- `DJANGO_SECRET_KEY` = (paste from Step 1)
- `DJANGO_DEBUG` = `false`
- `DJANGO_SITE_DOMAIN` = `nayiraah.org`
- `DJANGO_ALLOWED_HOSTS` = `nayi-raah-abc123.vercel.app,nayiraah.org,www.nayiraah.org`
- `DJANGO_CSRF_TRUSTED_ORIGINS` = `https://nayi-raah-abc123.vercel.app,https://nayiraah.org,https://www.nayiraah.org`

### Step 3️⃣: Commit & Push Code (1 min)
```powershell
cd d:\Microsoft_Nitesh\nayi_raah\nayi_raah\nayiraah
git add .
git commit -m "Deploy: Ready for Vercel"
git push origin main
```

### Step 4️⃣: Vercel Deploys Automatically (5 min)
- Vercel detects your push
- Builds automatically
- Deploys your site
- ✅ Done!

### Step 5️⃣: Test Your Site (5 min)
- Visit your URL
- Test all pages
- Test contact form
- ✅ Verify everything works
